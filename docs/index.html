1. 이 장치로 할 수 있는 것

    
밖에서 텔레그램 버튼 하나로 집 PC를 켜고 끌 수 있어요. 노트북이나 태블릿으로 집 PC에 원격 접속(Jump Desktop, 크롬 원격 데스크톱 등)하기 전에, 꺼져 있는 PC를 켜는 용도예요.

    
    
      
  • 공유기 설정(포트포워딩, WOL)이 필요 없어서 원룸·기숙사처럼 공유기를 못 건드리는 곳에서도 돼요.
    • 
      
  • PC가 켜졌는지 꺼졌는지 스스로 확인하고 결과를 알려 줘요.
    • 
      
  • 케이스 전원 버튼은 원래대로 그대로 쓸 수 있어요.
    • 
    


    
2. 준비물

    

      
항목설명

      
본체 모듈ESP32-C3 보드 + 옵토커플러(PC817) + 330Ω 저항 + 10kΩ 저항(GPIO4–GND, 보드가 켜지는 순간 버튼이 눌리는 것 방지). 직접 만들 땐 ESP32-C3 SuperMini 또는 XIAO ESP32C3를 써요.

      
전원 스위치 분배 케이블메인보드 전원 버튼 핀 2개를 케이스 버튼과 모듈이 같이 쓰게 나눠 주는 2핀 Y 케이블

      
USB 케이블데이터 전송이 되는 USB-C 케이블 (충전 전용 케이블은 설정이 안 돼요)

      
텔레그램휴대폰에 텔레그램 앱과 계정

      
설정용 브라우저그 PC의 크롬 또는 엣지

    


    
3. 설치하기

    
작업 전에 PC를 끄고 파워 서플라이 플러그를 뽑아 주세요. PC가 꺼져 있어도 메인보드에는 대기 전원이 흐르고 있어요.

    
3-1. 메인보드 전원 버튼 핀에 연결

    
    
      
  1. 메인보드 설명서에서 전면 패널 헤더의 PWR_SW(또는 PW+/PW−, POWER SW) 위치를 찾아요. RESET 핀과 헷갈리지 않게 주의해 주세요.
    2. 
      
  2. 케이스 전원 버튼 선을 PWR_SW에서 빼고, 그 자리에 Y 분배 케이블을 꽂아요.
    3. 
      
  3. Y 케이블의 한쪽엔 케이스 버튼 선을, 다른 쪽엔 모듈 선을 연결해요.
    4. 
      
  4. 모듈 선은 극성이 있어요. PC817 4번(컬렉터) 선을 PWR_SW +에, 3번(이미터) 선을 PWR_SW −에 연결해요. 헷갈리면 PC가 꺼진 상태(플러그는 꽂힘)에서 멀티미터로 두 핀 사이를 재 보세요. 3.3~5V가 나오는 쪽이 +예요. 반대로 꽂아도 고장 나진 않고, 버튼이 안 눌릴 뿐이에요.
    5. 
    

    
3-2. USB 연결

    
    
      
  • 모듈을 PC 후면 USB 포트에 꽂아요. 이 USB로 전원도 받고 설정도 해요.
    • 
      
  • 금속 케이스 안쪽은 와이파이가 약해요. 모듈은 케이스 밖 뒤쪽에 두고 전원 버튼 선만 확장 슬롯 틈으로 빼는 걸 추천해요. 외장 안테나가 있는 보드라면 안테나를 케이스 밖으로 빼 주세요.
    • 
      
  • 선이 팬에 닿지 않게 케이블타이로 고정하고, 모듈의 금속 핀이 케이스 철판에 닿지 않게 해 주세요(수축튜브나 작은 케이스 권장).
    • 
    


    
4. PC 설정 (BIOS·윈도우)

    
4-1. BIOS: ErP(EuP) 끄기 — 꼭 필요해요

    
ErP가 켜져 있으면 PC가 꺼질 때 USB 전원도 같이 끊겨서 모듈이 꺼져요. BIOS(부팅 때 Del 또는 F2)에서 ErP / EuP Ready / Deep Sleep 같은 항목을 Disabled로 바꿔 주세요. 메뉴 이름은 제조사마다 달라요.

    
확인 방법: PC를 끈 뒤에도 모듈의 LED나 USB 마우스 불이 계속 켜져 있으면 OK예요.

    
4-2. 윈도우: 전원 버튼 동작

    
제어판 → 전원 옵션 → 전원 단추 작동 설정 → "전원 단추를 누를 때"를 시스템 종료로 바꿔요. 이래야 텔레그램 끄기가 정상 종료로 동작해요.

    
4-3. 윈도우: USB 절전 끄기 (상태 확인 정확도)

    
이 장치는 USB 신호로 PC가 켜졌는지 판단해요. 윈도우가 USB 포트를 재우면 켜져 있는데도 꺼진 걸로 보일 수 있어요.

    
    
      
  • 제어판 → 전원 옵션 → 고급 전원 관리 → USB 설정 → USB 선택적 절전 모드를 사용 안 함으로 바꿔요.
    • 
      
  • 장치 관리자 → 범용 직렬 버스 컨트롤러 → 각 USB 루트 허브 → 전원 관리 탭 → "전원을 절약하기 위해 컴퓨터가 이 장치를 끌 수 있음" 체크 해제.
    • 
    

    
설정이 끝나면 PC를 켜 둔 채로 몇 시간 뒤 텔레그램에서 📊 상태를 눌러 계속 "켜짐"으로 나오는지 한 번 확인해 주세요.


    
5. 처음 설정하기

    
모듈이 PC USB에 꽂혀 있고 PC가 켜진 상태에서, 설정 페이지를 그 PC의 크롬/엣지로 열어요. 설정 페이지는 인터넷 주소(https)로 열어야 해요. PC에 저장된 HTML 파일을 직접 열면 펌웨어 설치가 안 돼요.

    
    
      
  1. 펌웨어 설치 (처음 한 번, 이미 설치된 모듈이면 생략): 설정 탭의 펌웨어 설치·업데이트 → 목록에서 보드 선택 → 설치. 처음 설치할 땐 "기기 지우기"를 체크해요. 1~2분 걸려요.
    2. 
      
  2. 기기 연결: 오른쪽 위 버튼 → 목록에서 USB JTAG/serial debug unit 선택. 상태 카드에 펌웨어 버전이 보이면 연결된 거예요.
    3. 
      
  3. 와이파이: 주변 와이파이 찾기 → 이름 고르고 비밀번호 입력 → 연결. 20초 안에 결과가 나와요.
    4. 
      
  4. 텔레그램 봇: 화면 안내대로 @BotFather에서 봇을 만들고 토큰을 붙여 넣어 확인을 눌러요. "@봇이름 확인됐어요"가 나오면 성공이에요. 봇 메시지 언어(한국어/영어)도 여기서 고를 수 있어요.
    5. 
      
  5. 내 텔레그램 등록: 등록 QR 만들기 → 휴대폰 카메라로 QR을 찍으면 텔레그램이 열려요 → 시작을 누르면 등록 끝. 채팅창 아래에 버튼 4개가 생겨요. QR은 10분 동안만 유효해요.
    6. 
    

    
설정은 모듈에 저장되니까 이 페이지는 닫아도 돼요.


    
6. 사용하기

    

      
버튼하는 일

      
🟢 켜기전원 버튼을 0.5초 눌러요. 이미 켜져 있으면 누르지 않아요. 40초 뒤 켜졌는지 알려 줘요.

      
⚪ 끄기"PC를 끌까요?" 확인 버튼이 떠요. 끄기를 누르면 윈도우 정상 종료가 시작되고 90초 뒤 결과를 알려 줘요.

      
📊 상태PC 켜짐/꺼짐, 와이파이 신호, 모듈 가동 시간, 펌웨어 버전을 보여 줘요.

      
⛔ 강제 종료PC가 멈췄을 때만 써요. 확인 후 전원 버튼을 6초 눌러 강제로 꺼요. 저장 안 한 작업은 사라져요.

    

    
    
      
  • 버튼 대신 /on /off /status /force /help를 보내도 돼요.
    • 
      
  • 확인 버튼은 1분 동안만 유효해요. 시간이 지나면 다시 눌러 주세요.
    • 
      
  • 켜기·끄기를 누른 뒤 결과를 알려 주기 전(켜기 40초, 끄기 90초)에는 같은 명령을 다시 보내도 실행하지 않아요. 연타 때문에 부팅 중에 다시 꺼지는 걸 막기 위해서예요. ⛔ 강제 종료는 언제든 돼요.
    • 
      
  • 와이파이나 텔레그램이 30분 넘게 안 되면 모듈이 스스로 재시작해요. 다시 연결되면 그 이유가 담긴 "보드가 다시 켜졌어요" 알림이 와요.
    • 
      
  • 모듈이 꺼져 있던 동안 보낸 명령이나 2분 넘게 지난 명령은 실행하지 않고 한 번에 알려 줘요. 정전 뒤에 엉뚱하게 켜지거나 꺼지는 걸 막기 위해서예요.
    • 
      
  • 정전 등으로 모듈이 다시 켜지면 "보드가 다시 켜졌어요" 알림이 와요.
    • 
      
  • 등록되지 않은 사람이 봇에 메시지를 보내도 아무 일도 일어나지 않아요.
    • 
    


    
7. 휴대폰 바로가기 만들기

    
안드로이드

    
텔레그램에서 봇 채팅방 → 오른쪽 위 ⋮ → 바로가기 추가(홈 화면에 추가). 홈 화면 아이콘 → 🟢 켜기, 두 번 탭으로 끝나요.

    
아이폰

    
단축어 앱 → 새 단축어 → URL 열기 동작 추가 → 주소에 tg://resolve?domain=봇아이디(@ 빼고) 입력 → 공유 버튼 → 홈 화면에 추가. 아이콘을 누르면 봇 채팅방이 바로 열려요.


    
8. 원격 접속 프로그램과 함께 쓰기

    • 
      
  • 밖에서: 🟢 켜기 → "켜진 걸 확인했어요" 알림 → 1~2분 뒤 원격 접속.
    • 
      
  • 작업이 끝나면 원격 접속 안에서 종료하거나 텔레그램 ⚪ 끄기를 써요.

9. 문제 해결

    

      
증상확인할 것

      
봇이 아무 대답을 안 해요PC가 꺼진 상태에서 모듈 전원이 살아 있는지(4-1 ErP), 와이파이가 바뀌지 않았는지 확인해 주세요. 집에서 이 페이지로 연결하면 상태 카드에서 원인이 보여요.

      
켜기를 눌렀는데 안 켜져요PWR_SW 위치와 극성(3-1)을 확인해 주세요. 케이스 버튼으로는 켜지는지도 확인해 주세요.

      
켜져 있는데 "꺼짐"으로 나와요윈도우 USB 절전(4-3)을 꺼 주세요. USB 허브를 거치지 말고 메인보드 후면 포트에 바로 꽂아 주세요.

      
끄기를 눌렀는데 안 꺼져요윈도우 전원 단추 동작(4-2)이 "시스템 종료"인지 확인해 주세요. 저장 안 한 문서 때문에 종료가 멈췄다면 ⛔ 강제 종료를 쓸 수 있어요.

      
"보드가 다시 켜졌어요"가 자주 와요USB 케이블이나 포트를 바꿔 보세요. PC를 켤 때 USB 전원이 잠깐 끊기는 메인보드도 있는데, 이건 정상이에요.

      
"크롬에서 설치할 수 없다"고 떠요PC에 저장된 HTML 파일을 직접 열었을 가능성이 커요. 설정 페이지를 https 주소로 열어 주세요.

      
기기 연결 목록에 안 보여요데이터용 USB 케이블인지, 크롬/엣지인지, 아두이노 IDE 같은 다른 프로그램이 포트를 쓰고 있지 않은지 확인해 주세요.

      
와이파이 연결이 실패해요2.4GHz인지, 비밀번호가 맞는지 확인해 주세요. 웹 로그인·기업용 인증 와이파이는 안 돼요. 신호가 약하면 모듈을 케이스 밖으로 빼고, SuperMini라면 고급 설정의 "와이파이 출력 낮추기"를 켜 보세요.

      
"토큰 오류"가 떠요BotFather에서 토큰을 다시 발급했다면 새 토큰을 2단계에 다시 넣어 주세요.

      
"예전에 보낸 명령이라 실행하지 않았어요"정상 동작이에요. 버튼을 한 번 더 눌러 주세요.

      
"방금 전원 버튼을 눌렀어요. 잠시만 기다려 주세요"정상 동작이에요. 결과 알림이 온 뒤에 다시 눌러 주세요.

      
펌웨어 설치가 실패하거나 설치 목록에 안 보여요USB를 뽑고, 보드의 BOOT(B) 버튼을 누른 채로 다시 꽂은 다음 설치를 눌러요. 설치가 끝나면 USB를 한 번 뽑았다 꽂아요.

    


    
10. 보안 안내

    
    
      
  • 등록된 텔레그램 계정 하나에서 보낸 명령만 실행해요. 계정을 지키기 위해 텔레그램 2단계 인증(비밀번호)을 꼭 켜 주세요.
    • 
      
  • 설정과 펌웨어는 USB로 PC에 꽂혀 있을 때 이 페이지에서만 바꿀 수 있어요. 무선으로 바꾸는 통로는 없어요.
    • 
      
  • 모듈은 PC의 파일이나 화면에 접근하지 않아요. 전원 버튼을 누르는 것과 USB 신호로 켜짐 여부를 보는 것만 해요. ESP32-C3의 USB는 시리얼 전용이라 키보드로 위장할 수 없어요.
    • 
      
  • 봇 토큰이 유출됐다면 BotFather에서 /revoke로 새 토큰을 받고 2단계에 다시 넣어 주세요. 토큰이 있어도 등록된 계정이 아니면 PC는 못 켜지만, 봇을 먹통으로 만들 수는 있어요.

1. What it does

    
Turn your home PC on and off from anywhere with one tap in Telegram. It's made for switching on a PC that's off before you connect to it remotely (Jump Desktop, Chrome Remote Desktop, etc.) from a laptop or tablet.

    
    
      
  • No router setup (port forwarding, Wake-on-LAN) needed, so it works in apartments and dorms where you can't touch the router.
    • 
      
  • It checks whether the PC actually turned on or off and tells you.
    • 
      
  • The case power button keeps working as before.
    • 
    


    
2. What you need

    

      
ItemDetails

      
ModuleESP32-C3 board + optocoupler (PC817) + 330 Ω resistor + 10 kΩ resistor (GPIO4 to GND, keeps the button from being pressed while the board boots). For a DIY build, use an ESP32-C3 SuperMini or XIAO ESP32C3.

      
Power switch splitterA 2-pin Y cable so the case button and the module share the motherboard power-button pins

      
USB cableA USB-C cable that carries data (charge-only cables can't be used for setup)

      
TelegramThe Telegram app and an account on your phone

      
Browser for setupChrome or Edge on that PC

    


    
3. Installation

    
Shut down the PC and unplug the power supply before you start. The motherboard still carries standby power while the PC is off.

    
3-1. Connect to the power-button pins

    
    
      
  1. Find the PWR_SW (or PW+/PW−, POWER SW) pins on the front-panel header in your motherboard manual. Don't confuse them with RESET.
    2. 
      
  2. Unplug the case power-button lead from PWR_SW and plug the Y splitter in its place.
    3. 
      
  3. Connect the case button lead to one branch of the Y cable and the module lead to the other.
    4. 
      
  4. The module lead has polarity: PC817 pin 4 (collector) goes to PWR_SW +, pin 3 (emitter) to PWR_SW −. If unsure, measure between the two pins with a multimeter while the PC is off but plugged in — the pin reading 3.3–5 V is +. Reversing it won't damage anything; the button just won't press.
    5. 
    

    
3-2. USB connection

    
    
      
  • Plug the module into a rear USB port on the PC. It gets power and settings over this USB.
    • 
      
  • Wi-Fi is weak inside a metal case. Keep the module outside at the back and route only the power-button lead through an expansion-slot gap. If your board has an external antenna, put the antenna outside the case.
    • 
      
  • Secure the wires away from fans with cable ties, and keep the module's metal pins off the case panels (heat-shrink or a small enclosure helps).
    • 
    


    
4. PC settings (BIOS and Windows)

    
4-1. BIOS: turn off ErP (EuP) — required

    
With ErP on, USB power is cut when the PC shuts down, so the module turns off too. In the BIOS (Del or F2 at boot), set ErP / EuP Ready / Deep Sleep to Disabled. The name varies by manufacturer.

    
To check: after shutting down, the module's LED or your USB mouse light should stay on.

    
4-2. Windows: power button action

    
Control Panel → Power Options → Choose what the power buttons do → set "When I press the power button" to Shut down. This makes Telegram's Shut down a normal shutdown.

    
4-3. Windows: turn off USB power saving (accurate status)

    
The module tells whether the PC is on from USB activity. If Windows puts the USB port to sleep, a running PC can look off.

    
    
      
  • Control Panel → Power Options → Advanced power settings → USB settings → set USB selective suspend to Disabled.
    • 
      
  • Device Manager → Universal Serial Bus controllers → each USB Root Hub → Power Management tab → untick "Allow the computer to turn off this device to save power".
    • 
    

    
Afterwards, leave the PC on for a few hours and tap 📊 Status in Telegram to confirm it still shows "on".


    
5. First-time setup

    
With the module plugged into the PC's USB and the PC on, open the settings page in Chrome or Edge on that PC. Open it from its web address (https) — firmware install doesn't work if you open a saved HTML file directly.

    
    
      
  1. Install firmware (first time only; skip if already installed): Settings tab → Install / update firmware → pick the board → Install. Tick "Erase device" on a first install. Takes 1–2 minutes.
    2. 
      
  2. Connect: top-right button → choose USB JTAG/serial debug unit. When the status card shows the firmware version, you're connected.
    3. 
      
  3. Wi-Fi: Scan for Wi-Fi → pick the network, enter the password → Connect. The result appears within 20 seconds.
    4. 
      
  4. Telegram bot: create a bot with @BotFather as shown, paste the token and click Verify. "@botname verified" means success. You can also choose the bot language (Korean/English) here.
    5. 
      
  5. Register my Telegram: Create registration QR → scan it with your phone camera to open Telegram → tap Start. Four buttons appear at the bottom of the chat. The QR is valid for 10 minutes.
    6. 
    

    
Settings are stored on the module, so you can close the page afterwards.


    
6. Everyday use

    

      
ButtonWhat it does

      
🟢 Power onPresses the power button for 0.5 s. Does nothing if the PC is already on. Confirms after 40 s.

      
⚪ Shut downAsks "Shut down the PC?". Tap Shut down to start a normal Windows shutdown; it confirms after 90 s.

      
📊 StatusShows PC on/off, Wi-Fi signal, module uptime and firmware version.

      
⛔ Force offOnly for a frozen PC. After you confirm, it holds the power button for 6 s. Unsaved work is lost.

    

    
    
      
  • You can also send /on /off /status /force /help.
    • 
      
  • Confirmation buttons are valid for 1 minute. After that, tap again.
    • 
      
  • After Power on or Shut down, the same command is not run again until the result arrives (40 s for power on, 90 s for shut down). This stops a double tap from turning the PC off mid-boot. ⛔ Force off always works.
    • 
      
  • If Wi-Fi or Telegram is unreachable for over 30 minutes, the module restarts itself. Once it reconnects, a "The module restarted" message tells you why.
    • 
      
  • Commands sent while the module was off, or older than 2 minutes, are not run; you get one notice about them. This prevents surprise power changes after an outage.
    • 
      
  • If the module restarts (e.g. after a power cut), you get a "The module restarted" message.
    • 
      
  • Messages from anyone who isn't registered do nothing.
    •

9. Troubleshooting

    

      
SymptomWhat to check

      
The bot doesn't replyCheck that the module stays powered while the PC is off (4-1 ErP) and that your Wi-Fi hasn't changed. At home, connect this page and the status card shows the cause.

      
Power on does nothingCheck the PWR_SW pins and polarity (3-1), and whether the case button still works.

      
Shows "off" while the PC is onTurn off Windows USB power saving (4-3). Plug into a rear motherboard port, not a hub.

      
Shut down doesn't turn it offCheck the Windows power button action (4-2) is "Shut down". If an unsaved document blocks shutdown, use ⛔ Force off.

      
"The module restarted" appears oftenTry another USB cable or port. Some motherboards briefly cut USB power when the PC turns on — that's normal.

      
"Can't install in this browser" appears in ChromeYou probably opened a saved HTML file directly. Open the settings page from its https address.

      
The module isn't in the Connect listUse a data USB cable and Chrome/Edge, and close other programs (e.g. Arduino IDE) using the port.

      
Wi-Fi won't connectUse 2.4 GHz and check the password. Web-login and enterprise Wi-Fi aren't supported. If the signal is weak, move the module outside the case; on a SuperMini, try "Lower Wi-Fi transmit power" in Advanced.

      
"Token error"If you regenerated the token in BotFather, enter the new one in step 2.

      
"That command was sent earlier, so it wasn't run"This is expected. Just tap the button again.

      
"I just pressed the power button. Please wait"This is expected. Tap again after the result arrives.

      
Firmware install fails, or the board isn't in the installer listUnplug the USB, hold the board's BOOT (B) button while plugging it back in, then click install. When it finishes, unplug and replug the USB once.

    


    
10. Security

    
    
      
  • Only commands from the one registered Telegram account are run. Turn on Telegram two-step verification (password) to protect that account.
    • 
      
  • Settings and firmware can only be changed from this page while the module is plugged into the PC over USB. There is no wireless way to change them.
    • 
      
  • The module can't access the PC's files or screen. It only presses the power button and reads USB activity. The ESP32-C3's USB is serial-only, so it can't pretend to be a keyboard.
    • 
      
  • If your bot token leaks, use /revoke in BotFather and enter the new token in step 2. A leaked token can't turn on your PC without the registered account, but it can disrupt the bot.
    •

    • 
      
  • New phone: create a new registration QR in step 3 and scan it with the new phone.
    • 
      
  • Moving or new router: connect to the new Wi-Fi in step 1.
    • 
      
  • Factory reset: Advanced → Factory reset. Wi-Fi, bot and registration are all erased.
